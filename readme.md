# Patrón de Diseño Singleton

## Autor
Luis Alejandro Banegas Andrade

## Materia
Programación Orientada a Objetos

## Descripción
Este proyecto demuestra la implementación del patrón de diseño Singleton utilizando TypeScript.

## Problema
Una aplicación de gestión de inventario requiere compartir una única configuración global entre los módulos de Ventas, Compras, Inventario y Reportes.

## Solución
Se implementa una clase ConfiguracionSistema mediante el patrón Singleton para garantizar una única instancia compartida por toda la aplicación.
